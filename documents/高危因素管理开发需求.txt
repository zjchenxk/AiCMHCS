开发高危因素管理功能，菜单路由/system/highRiskFactor，数据库表名为BASE_HIGH_RISK_FACTOR，达梦数据库建表语句如下：
CREATE TABLE BASE_HIGH_RISK_FACTOR(
    ID CHAR(36) NOT NULL,
    RISK_FACTOR_CATEGORY VARCHAR(50),
    RISK_FACTOR_SUBCATEGORY VARCHAR(50),
    RISK_FACTOR_CODE VARCHAR(20) NOT NULL,
    RISK_FACTOR_NAME VARCHAR(200) NOT NULL,
    RISK_COLOR VARCHAR(10),
    RISK_LEVEL VARCHAR(10),
    RISK_SCORE TINYINT,
    CREATOR_ID CHAR(36) NOT NULL,
    CREATOR_NAME VARCHAR(30) NOT NULL,
    HOSP_ID CHAR(36) NOT NULL,
    HOSP_NAME VARCHAR(100) NOT NULL,
    CREATE_TIME TIMESTAMP NOT NULL,
    UPDATE_TIME TIMESTAMP,
    PRIMARY KEY (ID)
);
COMMENT ON TABLE BASE_HIGH_RISK_FACTOR IS '高危因素字典表';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR.ID IS '主键（UUID v7）';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR.RISK_FACTOR_CATEGORY IS '大类';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR.RISK_FACTOR_SUBCATEGORY IS '小类';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR.RISK_FACTOR_CODE IS '高危因素编码';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR.RISK_FACTOR_NAME IS '高危因素名称';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR.RISK_COLOR IS '高危颜色（绿色/黄色/橙色/红色/紫色）';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR.RISK_LEVEL IS '高危等级（如Ⅰ、Ⅱ、Ⅲ，或A、B等）';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR.RISK_SCORE IS '高危分值';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR.CREATOR_ID IS '创建人ID（UUID v7）';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR.CREATOR_NAME IS '创建人姓名';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR.HOSP_ID IS '医院ID（UUID v7）';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR.HOSP_NAME IS '医院名称';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR.CREATE_TIME IS '创建时间';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR.UPDATE_TIME IS '更新时间';

要求：
1. 可以新增、修改和删除高危因素，新增权限代码为9909000001，修改权限代码为9909000002，删除权限代码为9909000003。
2. UI界面左侧显示高危因素列表
   1. 按【RISK_COLOR】分组，每组显示对应颜色背景
   2. 每组内，按【RISK_FACTOR_CATEGORY】->【RISK_FACTOR_SUBCATEGORY】->【RISK_FACTOR_NAME】，显示树形高危因素列表。如果【RISK_FACTOR_CATEGORY】、【RISK_FACTOR_SUBCATEGORY】为空，则将【RISK_FACTOR_NAME】置顶层。
   3. 高危因素名称【RISK_FACTOR_NAME】末尾显示高危因素编码【RISK_FACTOR_CODE】。
3. UI界面右侧显示高危因素新增/修改编辑区
   1. 高危颜色【RISK_COLOR】支持选择，数据库存储汉字，如：绿色、黄色、橙色、红色、紫色
   2. 高危等级【RISK_LEVEL】支持从数据字典表BASE_DICT和BASE_DICT_ITEM读取，DICT_CODE=99010001，默认存储BASE_DICT_ITEM表的ITEM_VALUE
