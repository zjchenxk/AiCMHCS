法定节假日设置功能需求

1. 菜单名称【法定节假日】，路由【/system/holiday】

2. 数据库法定节假日表，名称为【BASE_HOLIDAY】，达梦数据库建表语句如下：

CREATE TABLE BASE_HOLIDAY(
    ID BIGINT NOT NULL IDENTITY(1,1),
    START_DATE DATE NOT NULL,
    END_DATE DATE NOT NULL,
    HOLIDAY_TYPE TINYINT NOT NULL,
    CREATOR_ID CHAR(36) NOT NULL,
    CREATOR_NAME VARCHAR(30) NOT NULL,
    HOSP_ID CHAR(36) NOT NULL,
    HOSP_NAME VARCHAR(100) NOT NULL,
    CREATE_TIME TIMESTAMP NOT NULL,
    UPDATE_TIME TIMESTAMP,
    PRIMARY KEY (ID)
);
COMMENT ON TABLE BASE_HOLIDAY IS '国家法定节假日表';
COMMENT ON COLUMN BASE_HOLIDAY.ID IS '主键';
COMMENT ON COLUMN BASE_HOLIDAY.START_DATE IS '起始日期';
COMMENT ON COLUMN BASE_HOLIDAY.END_DATE IS '截止日期';
COMMENT ON COLUMN BASE_HOLIDAY.HOLIDAY_TYPE IS '节假日类型（1-元旦，2-春节，3-清明节，4-劳动节，5-端午节，6-中秋节，7-国庆节，8-其它）';
COMMENT ON COLUMN BASE_HOLIDAY.CREATOR_ID IS '创建人ID（UUID v7）';
COMMENT ON COLUMN BASE_HOLIDAY.CREATOR_NAME IS '创建人姓名';
COMMENT ON COLUMN BASE_HOLIDAY.HOSP_ID IS '医院ID（UUID v7）';
COMMENT ON COLUMN BASE_HOLIDAY.HOSP_NAME IS '医院名称';
COMMENT ON COLUMN BASE_HOLIDAY.CREATE_TIME IS '创建时间';
COMMENT ON COLUMN BASE_HOLIDAY.UPDATE_TIME IS '更新时间';

3. 支持法定节假日新增、修改和删除操作，新增操作权限代码为【9911000001】，修改操作权限代码为【9911000002】，删除操作权限代码为【9911000003】
