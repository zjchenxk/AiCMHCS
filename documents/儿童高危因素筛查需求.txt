下面我们改造一下儿童建档，添加儿童高危因素筛查功能，要求如下：

1. 在【监护人】TAB后面，添加一个【高危因素】TAB。

2. 在【高危因素】TAB页面中，根据数据库高危因素字典表【BASE_HIGH_RISK_FACTOR】的字段【RISK_COLOR】，创建绿色高危因素卡片、黄色高危因素卡片、橙色高危因素卡片、红色高危因素卡片和紫色高危因素卡片，每个卡片中根据字段【RISK_FACTOR_CATEGORY】和【RISK_FACTOR_SUBCATEGORY】建立一个树形高危因素列表，高危因素按字段【RISK_FACTOR_CODE】+【RISK_FACTOR_NAME】顺序排序，每个高危因素后显示一个复选框，允许勾选，参考high_risk_factor_management_page.dart。要求：如果选中了绿色卡片中的【无母亲及胎儿、新生儿的高危因素】，则不能选择【黄色】、【橙色】、【红色】和【紫色】卡片中的任一高危因素，应清除【黄色】、【橙色】、【红色】和【紫色】卡片中的选中高危因素。同样如果选中了【黄色】、【橙色】、【红色】和【紫色】卡片中的任一高危因素，则不能选择【绿色】卡片中的【无母亲及胎儿、新生儿的高危因素】。

3. 在【高危因素】TAB页面中，在顶部显示一个高危因素模糊搜索框，在搜索框中输入字符后，在5个卡片的高危因素名称中搜索匹配记录。如果无匹配记录，则提示【无匹配记录】。如果匹配成功，则自动滚动列表显示第一个匹配项，同时在搜索框后面显示匹配结果数量和当前显示项序号，格式为【当前显示序号/匹配结果数】，同时再显示一个【下一个】按钮，点击【下一个】按钮后，滚动列表顺序显示下一个匹配项，并更新当前显示序号。

4. 在【高危因素】TAB页面中，在顶部的高危因素模糊搜索框后面，再添加一个【新增高危因素】按钮，点击该按钮后，弹出高危因素新增对话框。
   1. 对话框界面中显示【高危颜色】下拉选择框，和【高危因素名称】输入框，以及【确定】和【取消】按钮。【高危颜色】下拉选择框支持选择【黄色】、【橙色】、【红色】和【紫色】，必填。【高危因素名称】输入框必填。
   2. 点击【确定】按钮，保存新增的高危因素。要求：
      1. 字段【RISK_FACTOR_CATEGORY】的值，默认为【其它】
      2. 字段【RISK_FACTOR_CODE】的值，当【高危颜色】选择【黄色】时则默认为【02990000】，当【高危颜色】选择【橙色】时则默认为【03990000】，当【高危颜色】选择【红色】时则默认为【04990000】，当【高危颜色】选择【紫色】时则默认为【05990000】。注意：字段【RISK_FACTOR_CODE】的值，允许存储重复数据。
      3. 保存成功后，关闭对话框，刷新高危因素卡片和列表，同时默认选中刚刚新增的高危因素，之前选中的高危因素同样要默认选中。
   3. 点击【取消】按钮，关闭对话框。
   
5. 点击儿童建档界面上的【保存】按钮时，将【高危因素】TAB页面中选中的高危因素，保存到数据库儿童高危因素表，表名为【CHILD_HIGH_RISK_FACTOR】，达梦数据库建表语句如下：
CREATE TABLE CHILD_HIGH_RISK_FACTOR(
    ID CHAR(36) NOT NULL,
    CHILD_ID CHAR(36) NOT NULL,
    HIGH_RISK_FACTOR CHAR(36) NOT NULL,
    RISK_FACTOR_CODE VARCHAR(20) NOT NULL,
    RISK_FACTOR_NAME VARCHAR(200) NOT NULL,
    RISK_COLOR VARCHAR(10),
    RISK_LEVEL VARCHAR(10),
    RISK_SCORE TINYINT,
    CREATOR_ID CHAR(36) NOT NULL,
    CREATOR_NAME VARCHAR(30) NOT NULL,
    DEPT_ID CHAR(36),
    DEPT_NAME VARCHAR(50),
    CAMPUS_ID CHAR(36),
    CAMPUS_NAME VARCHAR(50),
    HOSP_ID CHAR(36) NOT NULL,
    HOSP_NAME VARCHAR(100) NOT NULL,
    CREATE_TIME TIMESTAMP NOT NULL,
    UPDATE_TIME TIMESTAMP,
    PRIMARY KEY (ID)
);

COMMENT ON COLUMN CHILD_HIGH_RISK_FACTOR.RISK_LEVEL IS '高危等级（如Ⅰ、Ⅱ、Ⅲ，A、B等）';

经过测试，儿童建档功能的【高危因素】TAB页面需改进一下：
1. 顶部的高危因素搜索和新增操作Bar, 应放在滚动区域外。
2. 在高危因素模糊搜索框前面，添加快速导航按钮【绿色】、【黄色】、【橙色】、【红色】和【紫色】，点击导航按钮，将对应颜色的高危因素卡片滚动到视野中。
3. 输入搜索条件，匹配成功后，好象没有自动滚动到第一个匹配项。
4. 匹配成功后，能否高亮显示每一个匹配项？清除搜索框中的内容后，应清除所有高亮设置，以及清除搜索框后面的【当前显示序号/匹配结果数】。
5. 当选中绿色卡片中的【无母亲及胎儿、新生儿的高危因素】，不应该灰化禁用黄色、橙色、红色和紫色卡片中的所有高危因素复选框。同样选择黄色、橙色、红色和紫色卡片中的任一高危因素后，也不要灰化禁用绿色卡片中的【无母亲及胎儿、新生儿的高危因素】复选框。
6. 当选中绿色卡片中的【无母亲及胎儿、新生儿的高危因素】后，应自动清除黄色、橙色、红色和紫色卡片中所有选中高危因素的选择。同样选中黄色、橙色、红色和紫色卡片中的任一高危因素后，应自动清除绿色卡片中【无母亲及胎儿、新生儿的高危因素】的选择。
7. 我在儿童高危因素表【CHILD_HIGH_RISK_FACTOR】中添加了备注字段【REMARK】，server端的migrator代码已改，但其它代码都没改。要求：
   1. 在黄色、橙色、红色和紫色卡片的每个高危因素末尾显示一个【...】图标，点击【...】图标，弹出操作菜单，菜单中显示一个菜单项【备注】，点击【备注】菜单项，弹出备注编辑对话框，显示备注输入框，和确定、取消按钮。
   2. 在备注对话框中，输入备注后，点击【确定】按钮，将备注显示到高危因素名称后面，用括号（）括起来。
   3. 如果之前录入过备注，再次点击备注菜单项后，应将之前录入的备注内容显示到备注对话框中，供用户修改。
   4. 在儿童建档保存时，应将备注保存到数据库表【CHILD_HIGH_RISK_FACTOR】中。
8. 儿童建档保存时，如果选择的是绿色卡片中的【无母亲及胎儿、新生儿的高危因素】，则不用保存到数据库表【CHILD_HIGH_RISK_FACTOR】。
9. 当浏览一个儿童建档信息时，应在【高危因素】TAB页面的高危因素列表中，默认选中数据库表【CHILD_HIGH_RISK_FACTOR】中当前儿童的高危因素。如果表【CHILD_HIGH_RISK_FACTOR】中当前儿童没有高危因素，则默认选中绿色卡片中的【无母亲及胎儿、新生儿的高危因素】项。
