1. 开发指导建议模板管理功能，菜单路由/system/guidance。

2. 指导建议模板数据库表名为BASE_GUIDANCE_TEMPLATE，达梦数据库建表语句如下：

CREATE TABLE BASE_GUIDANCE_TEMPLATE(
    ID CHAR(36) NOT NULL,
    TEMPLATE_NAME VARCHAR(50) NOT NULL,
    DISPLAY_ORDER SMALLINT,
    CREATOR_ID CHAR(36) NOT NULL,
    CREATOR_NAME VARCHAR(30) NOT NULL,
    HOSP_ID CHAR(36) NOT NULL,
    HOSP_NAME VARCHAR(100) NOT NULL,
    CREATE_TIME TIMESTAMP NOT NULL,
    UPDATE_TIME TIMESTAMP,
    PRIMARY KEY (ID)
);
COMMENT ON TABLE BASE_GUIDANCE_TEMPLATE IS '指导建议模板表';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE.ID IS '主键（UUID v7）';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE.TEMPLATE_NAME IS '模板名称';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE.DISPLAY_ORDER IS '显示顺序';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE.CREATOR_ID IS '创建人ID（UUID v7）';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE.CREATOR_NAME IS '创建人姓名';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE.HOSP_ID IS '医院ID（UUID v7）';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE.HOSP_NAME IS '医院名称';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE.CREATE_TIME IS '创建时间';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE.UPDATE_TIME IS '更新时间';

3. 指导建议模板项目表名为BASE_GUIDANCE_TEMPLATE_ITEM，达梦数据库建表语句如下：

CREATE TABLE BASE_GUIDANCE_TEMPLATE_ITEM(
    ID CHAR(36) NOT NULL,
    TEMPLATE_ID CHAR(36) NOT NULL,
    GUIDANCE_TYPE VARCHAR(50) NOT NULL,
    GUIDANCE VARCHAR(1000) NOT NULL,
    IS_PERSONAL CHAR(1) NOT NULL,
    CREATOR_ID CHAR(36) NOT NULL,
    CREATOR_NAME VARCHAR(30) NOT NULL,
    DEPT_ID CHAR(36),
    DEPT_NAME VARCHAR(50),
    CAMPUS_ID CHAR(36),
    CAMPUS_NAME VARCHAR(50),
    HOSP_ID CHAR(36) NOT NULL,
    HOSP_NAME VARCHAR(100) NOT NULL,
    CREATE_TIME TIMESTAMP NOT NULL,
    UPDATE_TIME TIMESTAMP,
    PRIMARY KEY (ID)
);
COMMENT ON TABLE BASE_GUIDANCE_TEMPLATE_ITEM IS '指导建议模板项目表';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE_ITEM.ID IS '主键（UUID v7）';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE_ITEM.TEMPLATE_ID IS '模板ID（UUID v7）';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE_ITEM.GUIDANCE_TYPE IS '指导建议类别';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE_ITEM.GUIDANCE IS '指导建议';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE_ITEM.IS_PERSONAL IS '是否个人模板（0-否，1-是）';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE_ITEM.CREATOR_ID IS '创建人ID（UUID v7）';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE_ITEM.CREATOR_NAME IS '创建人姓名';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE_ITEM.DEPT_ID IS '科室ID（UUID v7）';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE_ITEM.DEPT_NAME IS '科室名称';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE_ITEM.CAMPUS_ID IS '院区ID（UUID v7）';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE_ITEM.CAMPUS_NAME IS '院区名称';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE_ITEM.HOSP_ID IS '医院ID（UUID v7）';
COMMENT ON COLUMN BASE_GUIDANCE_TEMPLATE_ITEM.HOSP_NAME IS '医院名称';

4. 界面分左右两部分：

   4.1. 左侧为模板列表，支持新增、修改和删除指导建议模板，新增操作权限代码为9912010001，修改操作权限代码为9912010002，删除操作权限代码为9912010003
   
   4.2. 右侧为指定模板的项目列表。支持新增、修改和删除指导意见，新增操作权限代码为9912020001，修改操作权限代码为9912020002，删除操作权限代码为9912020003







1. 取消左侧指导建议模板列表上的新增、修改和删除操作。

2. 修改右侧指导建议项目列表的操作权限代码，新增操作权限代码为9912000001，修改操作权限代码为9912000002，删除操作权限代码为9912000003

3. 同步改造初筛记录表指导建议对话框guidance_template_dialog.dart，要求如下：

   3.1. 删除数据库表【ASD_INITIAL_SCREENING_GUIDANCE】。

   3.2. 指导建议列表中的数据改从数据库表【BASE_GUIDANCE_TEMPLATE_ITEM】中获取，根据字段指导建议模板ID【TEMPLATE_ID】查询，并按字段指导建议类别【GUIDANCE_TYPE】排序，并且【GUIDANCE_TYPE】值为空的记录默认排最后。初筛指导建议模板ID默认为【01a21bb5-b4df-7000-bb50-bbb3c24a025d】。请将此查询方法做成公用方法，根据传入的指导建议模板ID查询数据。

   3.3. 指导建议新增和修改对话框，建议共用guidance_item_form_dialog.dart，根据传入的指导建议模板ID【TEMPLATE_ID】新增指导建议。
