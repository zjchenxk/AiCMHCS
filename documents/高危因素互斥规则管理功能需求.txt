开发高危因素互斥规则管理功能，菜单路由/system/highRiskFactorExclusion，数据库表名为BASE_HIGH_RISK_FACTOR_EXCLUSION，达梦数据库建表语句如下：
CREATE TABLE BASE_HIGH_RISK_FACTOR_EXCLUSION(
    ID CHAR(36) NOT NULL,
    FIRST_RISK_FACTOR_ID CHAR(36) NOT NULL,
    SECOND_RISK_FACTOR_ID CHAR(36) NOT NULL,
    THIRD_RISK_FACTOR_ID CHAR(36),
    CREATOR_ID CHAR(36) NOT NULL,
    CREATOR_NAME VARCHAR(30) NOT NULL,
    HOSP_ID CHAR(36) NOT NULL,
    HOSP_NAME VARCHAR(100) NOT NULL,
    CREATE_TIME TIMESTAMP NOT NULL,
    UPDATE_TIME TIMESTAMP,
    PRIMARY KEY (ID)
);
COMMENT ON TABLE BASE_HIGH_RISK_FACTOR_EXCLUSION IS '高危因素互斥规则表';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR_EXCLUSION.ID IS '主键（UUID v7）';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR_EXCLUSION.FIRST_RISK_FACTOR_ID IS '第一个高危因素ID（UUID v7）';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR_EXCLUSION.SECOND_RISK_FACTOR_ID IS '第二个高危因素ID（UUID v7）';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR_EXCLUSION.THIRD_RISK_FACTOR_ID IS '第三个高危因素ID（UUID v7）';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR_EXCLUSION.CREATOR_ID IS '创建人ID（UUID v7）';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR_EXCLUSION.CREATOR_NAME IS '创建人姓名';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR_EXCLUSION.HOSP_ID IS '医院ID（UUID v7）';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR_EXCLUSION.HOSP_NAME IS '医院名称';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR_EXCLUSION.CREATE_TIME IS '创建时间';
COMMENT ON COLUMN BASE_HIGH_RISK_FACTOR_EXCLUSION.UPDATE_TIME IS '更新时间';

1. 上表中的【第一个高危因素ID】、【第二个高危因素ID】和【第三个高危因素ID】，来源于表【BASE_HIGH_RISK_FACTOR】的主键【ID】。
